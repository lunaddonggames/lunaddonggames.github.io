About Us

Small games. Big feelings.

Lunaddong Game Studio is an independent mobile game studio from Korea. We build puzzle games you can start with one tap and still think about on the bus home.

Every game runs on our own shared engine, so each new title starts with the polish of the last one: the same instant feedback, the same care for motion, and the same respect for your time.
